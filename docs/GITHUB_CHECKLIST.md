# GitHub Publishing Checklist

1. Create a new GitHub repository named `cricket-scorer`.
2. Keep the repository public if you want recruiters to inspect it.
3. Upload the complete project structure.
4. Confirm `README.md` appears on the repository home page.
5. Confirm screenshots render correctly in the README.
6. Enable GitHub Pages from the repository's Pages settings using the main branch/root folder.
7. Open the generated live URL and test the application.
8. Add both GitHub and Live Demo links to your resume/portfolio.

Do not commit private personal information or unnecessary browser/editor files.
